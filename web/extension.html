Sara SOP in Chrome's side panel

Capture the current Chrome tab, name each image, add one description, and organize everything into a guide you can paste into Word.

Download Chrome extension

Install it in Chrome

  1. Download the ZIP above and extract it.
  2. Open chrome://extensions in Chrome and turn on Developer mode.
  3. Click Load unpacked and select the extracted chrome_extension folder.
  4. Click the Sara SOP icon in Chrome. The workspace opens on the right.

Use Capture this tab in the side panel to take a screenshot. Chrome blocks capture on protected pages such as chrome:// pages and the Chrome Web Store.
