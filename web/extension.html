Sara SOP in Chrome's side panel

Capture or import images, organize them into SOP steps, assign descriptions to image ranges, then copy everything into a document.

Download Chrome extension

Sara SOP Capture Privacy Policy

Install it in Chrome

  1. Download the ZIP above and extract it into a folder.
  2. Open chrome://extensions in Chrome and turn on Developer mode.
  3. Click Load unpacked and select the extracted folder that contains manifest.json.
  4. Click the Sara SOP icon in Chrome. The workspace opens on the right.

Review the Privacy Policy on first use. Click an image to open the full-page editor, where you can add images, rename and reorder them, draw red boxes, and assign descriptions to image ranges.
